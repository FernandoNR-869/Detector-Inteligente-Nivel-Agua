# Detector Inteligente de Nivel de Agua

Sistema económico basado en electrónica analógica para monitorear y alertar sobre los niveles (Bajo, Medio, Alto) de un depósito de agua.

## Arquitectura General
*   **Sensor:** Simulación de electrodos/flotador.
*   **Control lógico:** Amplificador operacional LM324.
*   **Indicadores:** 3 LEDs (Bajo, Medio, Alto) y 1 Buzzer activo.
*   **Conmutación:** Transistor BJT.
